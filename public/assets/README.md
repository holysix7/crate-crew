# MBG popup emblem

`mbg-logo.png` is the unmodified Badan Gizi Nasional emblem matching the reference supplied for the Bansos MBG game event.

- Source page: [Arti Logo BGN](https://www.bgn.go.id/logo-meaning)
- Original image: [logo-bgn.png](https://www.bgn.go.id/logo-bgn.png)
- Retrieved: 20 October 2026
- Original dimensions: 1122 × 1112; PNG, 1,027,560 bytes.

The file is bundled locally for LAN/offline play. It is requested only when an MBG warning or personal notification occurs, then reused from the browser cache. The popup uses an ordinary asynchronously decoded DOM image; it does not add a WebGL texture or block gameplay input.
